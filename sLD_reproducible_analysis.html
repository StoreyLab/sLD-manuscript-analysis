Introduction

This document contains code and supporting information accompanying the manuscript “A test for linkage disequilibrium in structured populations.” We organize the document by figure in order of appearance in the main text.

Some time-consuming chunks below are set not to run by default. Instead, we ran these code chunks on the ARGO SLURM cluster (managed by the Lewis-Sigler Institute for Integrative Genomics at Princeton University) and provide intermediate \(\texttt{.rds}\) files in the \(\texttt{rdata}\) directory to be loaded inside of plotting chunks. This directory contains sub-directories corresponding to each of the human studies we analyze in this study (\(\texttt{TGP\_rdata}\), \(\texttt{HGDP\_rdata}\), \(\texttt{HO\_rdata}\)), as well as a sub-directory for simulation studies (\(\texttt{power\_sim}\)). The \(\texttt{figures}\) directory in turn contains the output figures.

Datasets

Our analyses center on three human studies: the Thousand Genomes Project (TGP) (The 1000 Genomes Project Consortium et al. 2015), Human Genome Diversity Project (HGDP) (Cavalli-Sforza 2005), and Human Origins (HO) study (Lazaridis et al. 2014). We process the datasets in the same manner as was done in (Hao and Storey 2019). In brief, we filter out closely related individuals and genotypes with an allele frequency below \(0.05\) for each dataset, with some additional filtering on genotype completeness. Our resulting genotype matrices have the following dimensions:

  • TGP: \(1815\) individuals and \(1229310\) SNPs.
  • HGDP: \(940\) individuals and \(550303\) SNPs.
  • HO: \(2251\) individuals and \(372446\) SNPs.

The datasets analyzed in this study can be found in the Storey Lab repository for the \(\texttt{alstructure}\) manuscript (Cabreros and Storey 2019).

Our goal is to evaluate interchromosomal LD for different models of population structure. As such, we randomly draw a large number of locus pairs (\(2 \times 10^6\)) spanning different chromosomes. The following code chunks produce a file named \(\texttt{TGP\_diff\_chr\_ids.rds}\), containing pairs of indices corresponding to SNPs on distinct chromosomes within the TGP dataset; these indices are consistent with the ordering of SNPs in the file \(\texttt{TGP.bed}\). We keep this file in the directory \(\texttt{./rdata/TGP\_rdata/diff\_chr}\). We use the BioMart database to obtain information about SNPs (i.e., chromosome number, base pair coordinate) (Smedley et al. 2009). We include a helper function below named \(\texttt{sample\_across\_chromosomes()}\) that enables us to randomly sample pairs of loci spanning different chromosomes. We use this function here for the TGP, and call it later for the HGDP and HO datasets. We also add a simple function \(\texttt{match\_rsid\_index()}\) that allows us to identify the index of a given SNP in the original PLINK genotype dataset.

# Function for sampling locus pairs spanning two different chromosomes 
sample_across_chromosomes <- function(snp_info, n_pairs) {
  snps_by_chr <- split(snp_info$refsnp_id, snp_info$chr_name)
  chr_names <- as.character(1:22)
  pair_rsid <- matrix(nrow = n_pairs, ncol = 2)
  
  for (i in 1:n_pairs) {
    chr_pair <- sample(chr_names, 2, replace = FALSE)
    snp_a <- sample(snps_by_chr[[chr_pair[1]]], 1)
    snp_b <- sample(snps_by_chr[[chr_pair[2]]], 1)
    pair_rsid[i,] <- c(snp_a, snp_b)
  }
  
  return(pair_rsid)
}

match_rsid_index <- function(id_pairs, original_order) {
  locus_a_id <- match(id_pairs[,1], original_order)
  locus_b_id <- match(id_pairs[,2], original_order)
  
  return(cbind(locus_a_id, locus_b_id))
}

Perform sLD test on TGP data

We present a sample implementation below for performing the sLD test on the TGP dataset. The sLD test requires estimated individual-specific allele frequencies (IAFs) – as detailed in the main text, we employ a semiparametric estimator of the admixture model, called \(\texttt{alstructure}\) (Cabreros and Storey 2019). We truncate estimates to be in the range \([\tfrac{1}{2J}, 1 - \tfrac{1}{2J}]\), where \(J\) is the number of individuals, as is done for the related structural Hardy-Weinberg equilibrium (sHWE) test (Hao and Storey 2019); we do this to ensure that IAFs are not exactly equal to 0 or 1. In the example below, we model \(K = 3\) admixed populations.

Because it can be time-intensive to carry out the sLD test for a large number of locus pairs and/or a large range of admixed population counts \(K\), we recommend parallelizing this analysis. We performed this analysis using ARGO, a SLURM cluster under the Lewis- Sigler Institute for Integrative Genomics at Princeton University. ARGO consists of a combination of AMD EPYC and Intel Xeon compute nodes. We include a function for cluster jobs below named \(\texttt{sLD\_parallel()}\), which is compatible with multi-core processors. The argument \(\texttt{cores}\) specifies the number of cores.

sLD_parallel <- function(X, Pi, S, cores) {
  mclapply(1:nrow(S), function(i) {
    locus_a <- S[i, 1]
    locus_b <- S[i, 2]
    X_a <- X[locus_a, ]
    X_b <- X[locus_b, ]
    pi_a_vec <- Pi[locus_a, ]
    pi_b_vec <- Pi[locus_b, ]
    sLD_SNP(X_a, X_b, pi_a_vec, pi_b_vec)
  }, mc.cores = cores) |> unlist()
}

Figure 3

Here, we simulate genotypes under an admixture model with \(K=4\) admixed populations for \(J = 800\) individuals at \(I = 80000\) loci, using the \(\texttt{bnpsd}\) library (Ochoa and Storey 2021). We draw ancestral allele frequencies from the \(\text{Uniform}(0.05,0.95)\) distribution, admixed population allele frequencies via the Balding-Nichols distribution (Balding and Nichols 1995), and admixture proportions according to a Normal random walk along a one-dimensional geography (Ochoa and Storey 2016). We chose admixed population inbreeding coefficients of \(0.1, 0.2, 0.3\) and \(0.4\). IAFs are in turn estimated from the observed genotypes using \(\texttt{alstructure}\) under the assumption that the true number of admixed populations is known (i.e., setting \(K=4\)) (Cabreros and Storey 2019). We filter out loci with a minor allele frequency below 0.01.

Perform sLD test on null pairs

We perform the sLD test on \(50000\) randomly selected pairs of SNPs. We consider an unstructured population model (equivalent to \(K=1\) admixed populations), the true population model, and an estimated population model. The corresponding test types will be referred to as traditional, sLD (theoretical), and sLD (implemented), respectively. Because we draw genotypes jointly independent of one another, these pairs represent true null hypotheses (no structural LD). Note that we can equivalently use the function \(\texttt{sLD()}\) to compute test statistics. In this case, we would first compute a full set of locus pair indices, and input this set directly into \(\texttt{sLD()}\). We explicitly loop over \(\texttt{1:n\_pairs}\) here and use \(\texttt{sLD\_SNP()}\) to demonstrate how individual test statistics are computed.

Figure 4

We evaluate the statistical power of the sLD test, assessing whether it has the ability to detect true instances of structural LD. As such, we implement the forward-generating probability model for genotype pairs in structural LD outlined in the manuscript (specifically in the Appendices). We first generate IAFs for \(J = 800\) individuals at \(I = 200000\) loci under an admixture model with \(K=4\) admixed populations. Our simulation parameters and distributions closely mirror those used for Figure 3, only we have a larger number of loci here.

From these IAFs, we then draw genotypes – some in structural LD, and others not in structural LD. Genotype pairs not in structural LD are essentially jointly independent binomial draws in accordance with the coancestry model. For genotype pairs in structural LD, we must tune the value of their individual-specific LD coefficient \(\delta_{ab,j}\). Note that the possible values of \(\delta_{ab,j}\) are constrained, as detailed in the manuscript, by \(D_{\min}(\pi_{aj}, \pi_{bj})\) and \(D_{\max}(\pi_{aj}, \pi_{bj})\) – the minimum and maximum possible values of the LD coefficient given two allele frequencies \(\pi_{aj}\) and \(\pi_{bj}\). These constraints ensure that haplotype frequencies under our framework are non-negative values summing up to one. Thus, given \(\pi_{aj}\) and \(\pi_{bj}\), and assuming positive LD, we first compute \(D_{\max}(\pi_{aj}, \pi_{bj})\) and then set \[ \delta_{ab,j} = \min\{\rho_{ab} \sqrt{\pi_{aj}(1-\pi_{aj})\pi_{bj}(1-\pi_{bj})}, D_{\max}(\pi_{aj}, \pi_{bj})\}, \] where \(\rho_{ab}\) denotes some (non-negative) target conditional correlation. In our simulations, we chose a range of \(\rho_{ab}\) from \(0.1\) to \(0.5\) in increments of \(0.05\). Note that for a given value of \(\rho_{ab}\) in this analysis, all non-null pairs have that value of \(\rho_{ab}\) set as the target conditional correlation so that the signal of structural LD is consistent within a given simulation replicate. We conduct 300 simulation replicates for each value of \(\rho_{ab}\).

Perform sLD test on simulated null and non-null pairs

We provide a function \(\texttt{sim\_mat\_with\_haplo()}\) that generates a genotype matrix in which certain pairs of genotypes (for a given individual) are in structural LD. The helper function \(\texttt{run\_single\_simulation()}\) in turn runs one instance of our statistical power simulations, while \(\texttt{compute\_FDR\_power()}\) calculates the false discovery rate (FDR) and statistical power given a set of \(p\)-values, the indices corresponding to the true alternate hypotheses among these \(p\)-values, and a threshold for \(q\)-values.

compute_FDR_power <- function(p_val_vec, alt_ids, q_threshold) {
  
  q_val_vec <- qvalue(p_val_vec, pi0 = 1)
  rejected <- which(q_val_vec$qvalues <= q_threshold)
  FDR <- if (length(rejected) > 0) 
    length(setdiff(rejected, alt_ids)) / length(rejected) 
  else 0
  power <- length(intersect(rejected, alt_ids)) / length(alt_ids)
  
  return(c(FDR, power))
}

# m_kept can be adjusted if any filtering is done on minimum MAF
run_single_simulation <- function(s, p_ind, rho, q_threshold = 0.1, 
                                  m_kept = nrow(p_ind)) {
  
  # Generate genotypes
  pair_ids <- matrix(1:5000, ncol = 2, byrow = TRUE) # indices of non-null SNP pairs
  n_null_pairs <- 5e4 # number of null hypotheses
  alt_ids <- 1:2500 # indices of non-null p-values
  
  X <- sim_mat_with_haplo(p_ind, pair_ids, rho = rho)
  
  full_pairlist <- rbind(
    pair_ids,
    t(replicate(n_null_pairs, sample(5001:m_kept, 2)))
  )
  n_pairs <- nrow(full_pairlist)

  # Estimate and truncate IAFs
  p_hat <- estimate_F(X, d = 4)$F_hat
  J_ind <- ncol(p_hat)
  p_hat[p_hat < 1/(2*J_ind)] <- 1/(2*J_ind)
  p_hat[p_hat > 1 - 1/(2*J_ind)] <- 1 - 1/(2*J_ind)
  
  p_trad <- matrix(
    rowMeans(X/2, na.rm = TRUE),
    nrow = nrow(X), 
    ncol = ncol(X)
  )
  p_trad[p_trad < 1/(2*J_ind)] <- 1/(2*J_ind)
  p_trad[p_trad > 1 - 1/(2*J_ind)] <- 1 - 1/(2*J_ind)

  test_stat_theor_vec <- numeric(n_pairs)
  test_stat_imp_vec <- numeric(n_pairs)
  test_stat_trad_vec <- numeric(n_pairs)

  for (i in 1:n_pairs) {
    locus_a <- full_pairlist[i, 1]
    locus_b <- full_pairlist[i, 2]
    X_a <- X[locus_a, ]
    X_b <- X[locus_b, ]
    
    test_stat_theor_vec[i] <- sLD_SNP(X_a, X_b, p_ind[locus_a, ], p_ind[locus_b, ])
    test_stat_imp_vec[i] <- sLD_SNP(X_a, X_b, p_hat[locus_a, ], p_hat[locus_b, ])
    test_stat_trad_vec[i] <- sLD_SNP(X_a, X_b, p_trad[locus_a, ], p_trad[locus_b, ])
  }
  
  # Compute p-values 
  p_val_theor_vec <- compute_p_val(test_stat_theor_vec)
  p_val_imp_vec <- compute_p_val(test_stat_imp_vec)
  p_val_trad_vec <- compute_p_val(test_stat_trad_vec)
  
  # Compute FDR and power metrics
  out_theor <- compute_FDR_power(p_val_theor_vec, alt_ids, q_threshold = q_threshold)
  out_imp <- compute_FDR_power(p_val_imp_vec, alt_ids, q_threshold = q_threshold)
  out_trad <- compute_FDR_power(p_val_trad_vec, alt_ids, q_threshold = q_threshold)
  
  return(list(theor = out_theor, imp = out_imp, naive = out_trad))
}

Procedure for selecting \(K\)

We briefly describe our procedure for choosing the number of admixed populations \(K\) in an admixture model of population structure, which closely follows an algorithm introduced for the related sHWE test (Hao and Storey 2019). We analyze the TGP in this example. Specifically, for each value of \(K\), we compute the (Shannon) entropy of its corresponding \(p\)-value distribution (these are \(p\)-values computed for interchromosomal locus pairs). This process begins with partitioning the interval \([0,1]\) into \(B\) equally sized bins. We then compute the entropy, defined as \(-\sum_{b=1}^B f_b \log_2(f_b)\), where \(f_b\) is the proportion of \(p\)-values falling into the \(b\)th bin. We can choose the value of \(K\) corresponding to the largest entropy value, at the start of a plateau in entropy values, or via some other metric. In our analyses, we select the smallest value of \(K\) within an entropy plateau such that its corresponding histogram of \(p\)-values is qualitatively close to the \(\text{Uniform}(0,1)\) distribution.

The first function, \(\texttt{sample\_snp\_pairs\_by\_distance()}\), samples pairs of SNPs on a given chromosome within a physical distance (in base pairs) window \([\texttt{lower\_bound}, \texttt{upper\_bound}]\). # Helper functions for sampling locus pairs on a given chromosome
sample_snp_pairs_by_distance <- function(positions, rsids, lower_bound, upper_bound, 
                                         n_pairs = 1000, max_trials = 5e3) {
  n <- length(positions)
  pairs <- matrix(NA_integer_, nrow = n_pairs, ncol = 2)
  bp_distance <- numeric(n_pairs)
  count <- 0
  trials <- 0

  while (count < n_pairs && trials < max_trials) {
    i <- sample.int(n - 1, 1)
    pos_i <- positions[i]
    rel_dist <- positions[(i+1):n] - pos_i
    valid_j_rel <- which(rel_dist >= lower_bound & rel_dist <= upper_bound)

    if (length(valid_j_rel) > 0) {
      if (length(valid_j_rel) == 1) {
        j <- i + valid_j_rel
      } else {
        j <- i + sample(valid_j_rel, 1)
      }
      count <- count + 1
      pairs[count, ] <- c(rsids[i], rsids[j])
      bp_distance[count] <- abs(pos_i - positions[j])
    }
    trials <- trials + 1
  }

  if (count < n_pairs) {
    pairs <- pairs[1:count, , drop = FALSE]
    warning(sprintf("Only %d pairs found (target was %d)", count, n_pairs))
  }

  return(list(pairs = pairs, bp_distance = bp_distance))
}

sample_window_across_chr <- function(snp_df, lower_bound, upper_bound, 
                                    n_pairs_per_chr = 1000, 
                                    max_trials = n_pairs_per_chr*10) {
  
  window_ids <- matrix(nrow = 22*n_pairs_per_chr, ncol=2)
  window_distance <- numeric(22*n_pairs_per_chr)
  
  for (i in 1:22) {
    chr_df <- snp_df[snp_df$chr_name == i,]
    chr_df <- chr_df[order(chr_df$chrom_start, decreasing=F),]
    sampleid <- sample_snp_pairs_by_distance(chr_df$chrom_start, chr_df$refsnp_id,
                                             n_pairs = n_pairs_per_chr,
                                             max_trials = max_trials,
                                             lower_bound = lower_bound, 
                                             upper_bound = upper_bound)
    window_distance[((i-1)*n_pairs_per_chr+1):(i*n_pairs_per_chr)] <- sampleid$bp_distance
    window_ids[((i-1)*n_pairs_per_chr+1):(i*n_pairs_per_chr), ] <- sampleid$pairs
  }
  
  return(list(pairs = window_ids, bp_distance = window_distance))
}

We introduce a helper function \(\texttt{make\_binned\_df()}\) to generate a dataframe for plotting. We group \(-\log_{10}(p\)-values) into bins based on the physical distance between loci (within a given pair), then calculate the mean within these bins.

make_binned_df <- function(p_vec, distances) {
  
  x <- distances
  y <- -log10(p_vec)
  y <- pmin(y, 16) # truncate p-values 
  df <- data.frame(x = x, y = y)
  
  # Create bins and compute mean per bin 
  bin_width <- 0.25
  df_binned <- df %>%
    mutate(bin = cut(x, breaks = seq(0, 7, by = bin_width), include.lowest = TRUE)) %>%
    group_by(bin) %>%
    summarize(
      mean_x = mean(x, na.rm = TRUE),
      mean_y = mean(y, na.rm = TRUE, trim=0.05),
      var_x = var(x, na.rm = TRUE),
      var_y = var(y, na.rm = TRUE),
      .groups = "drop"
    )
    
  return(df_binned)
}

Figure 11

We evaluate the fit of the \(\text{Normal}(0,1)\) theoretical null distribution for the TGP by comparing it to an empirical null distribution (generated via the parametric bootstrap approach detailed in (Hao and Storey 2019)). From our simulated genotypes, we carry out a total of \(2 \times 10^6\) hypothesis tests, resulting in \(2 \times 10^6\) null test statistics. In order to see whether the empirical null distribution is approximately \(\text{Normal}(0,1)\) distributed, we compute two-sided \(p\)-values from our empirical test statistics using the \(\text{Normal}(0,1)\) cumulative distribution function (CDF). If the empirical null distribution is roughly \(\text{Normal}(0,1)\), we would expect to see a \(\text{Uniform}(0,1)\) distribution of \(p\)-values. We compute the two-sided \(p\)-value \(2(1-\Phi(\lvert T^{(J)}_{ab}(\hat{\mathbf{\Pi}}^0_{ab})\rvert))\) for each test statistic \(T^{(J)}_{ab}(\hat{\mathbf{\Pi}}^0_{ab})\), where \(\Phi(\cdot)\) denotes the \(\text{Normal}(0,1)\) CDF. To better visualize tail behavior, we chose to plot a quantile-quantile plot of \(p\)-values against theoretical uniform quantiles on a logarithmic axis, rather than comparing test statistic directly against \(\text{Normal}(0,1)\) quantiles. We perform this analysis for a wide range of admixed population counts \(K\).

Code for plotting

Because we analyzed a large number of \(p\)-values, we chose to sample a subset of them for each quantile-quantile plot to avoid a prohibitively large file size for the final figure. We restrict this downsampling to larger \(p\)-values, keeping all \(p\)-values \(< 0.01\) to preserve the tail behavior of our empirical distribution. We include a function below, \(\texttt{downsample\_indices()}\), that carries out this downsampling procedure; the argument \(\texttt{sample\_size}\) denotes the target number of \(p\)-values to keep. Note that we apply this downsampling to both the observed \(p\)-values as well as the paired theoretical \(\text{Uniform}(0,1)\) quantiles.

downsample_indices <- function(test_stats, sample_size=2e4) {
  
  # Sort test statistics in decreasing order (i.e., increasing p-values)
  n_total <- length(test_stats)
  abs_ts_sorted <- sort(abs(test_stats), decreasing = TRUE)
  p_sorted <- compute_p_val(abs_ts_sorted)
  p_theo_all <- ppoints(length(test_stats))
  
  # Keep all small p-values
  tail_indices <- which(p_sorted < 0.01) 
  if (length(tail_indices) > 0) {
    tail_limit <- max(tail_indices)
    tail_idx <- 1:tail_limit
  } else {
    tail_limit <- 0
    tail_idx <- integer(0)
  }
  
  # Downsample the "bulk" region containing larger p-values
  if (tail_limit < n_total) {
    bulk_start <- tail_limit + 1
    n_bulk <- n_total - bulk_start + 1
    if (n_bulk > sample_size) {
      bulk_idx <- unique(round(seq(bulk_start, n_total, length.out = sample_size)))
    } else {
      bulk_idx <- bulk_start:n_total
    }
  } else {
    bulk_idx <- integer(0)
  }
  
  keep_idx <- c(tail_idx, bulk_idx)
  return(list(obs = p_sorted[keep_idx], 
              theo = p_theo_all[keep_idx]))
}
